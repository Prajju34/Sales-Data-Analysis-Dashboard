## Project Overview

The Sales Data Analysis Dashboard analyzes sales data to understand business performance, product sales, regional performance, and profitability. It uses Python for data analysis and Streamlit to create an interactive dashboard.

## Objectives

- Clean and prepare the sales dataset.
- Calculate total sales, profit, orders, and units sold.
- Analyze monthly sales trends.
- Identify top-selling products.
- Compare sales and profit across regions and categories.
- Present business insights using charts and an interactive dashboard.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- GitHub

## Project Structure

- `data/` — Original and cleaned datasets, analysis results, and business insights.
- `notebooks/` — Python scripts for data cleaning, analysis, and chart creation.
- `dashboard/` — Interactive Streamlit dashboard and visualizations.
- `report/` — Project report and dashboard screenshots.

## How to Run the Dashboard

1. Install Python.
2. Install the required packages:

   `python -m pip install pandas numpy matplotlib streamlit`

3. Open a terminal in the project folder.
4. Run:

   `python -m streamlit run dashboard/app.py`

5. Open the local URL displayed in the terminal.
